# Project instructions

Read `README.md` before working in this repository. For Angular app work, also
read `app/README.md` and the relevant source files.

## Lazy-loaded documentation

- Before adding or changing home-page tiles, routes, embedded games, or Orbit
  integration, read [Tiles and Orbit integration](docs/tiles-and-orbit.md).

## Working conventions

- Check git status before making changes and preserve unrelated work.
- Do not stage or commit unless the user requests it.
- Keep new documentation, comments, and UI strings in English.
- Exclude `node_modules` when searching for project instructions or source files;
  avoid unrestricted recursive directory scans.
